🔧 LANGKAH 1: CEK PYTHON

Buka Command Prompt (Win+R → ketik "cmd" → Enter)

Cek Python:
    python --version

Harus muncul: Python 3.7.x atau lebih baru

Jika tidak ada Python:
    1. Download dari: https://www.python.org/downloads/
    2. Install dengan checklist "Add Python to PATH"
    3. Restart computer
    4. Coba lagi: python --version

    pip --version

    https://bootstrap.pypa.io/get-pip.py

⚠️  TROUBLESHOOTING LENGKAP

ERROR 1: "python: command not found"
─────────────────────────────────────
CAUSE: Python belum ter-install atau tidak di PATH
SOLUTION:
    1. Install Python dari python.org
    2. Saat install, CENTANG "Add Python to PATH"
    3. Restart computer
    4. Coba lagi

─────────────────────────────────────────────────────────────────

ERROR 2: "pip: command not found"
──────────────────────────────────
CAUSE: pip belum ter-install
SOLUTION:
    python -m ensurepip --upgrade
    atau
    python -m pip install --upgrade pip

─────────────────────────────────────────────────────────────────

ERROR 3: "No module named 'flask'"
───────────────────────────────────
CAUSE: Dependencies belum ter-install
SOLUTION:
    pip install Flask Flask-SocketIO python-socketio
    atau
    pip install -r requirements.txt

─────────────────────────────────────────────────────────────────

ERROR 4: "Port 5000 already in use"
────────────────────────────────────
CAUSE: Port 5000 sudah dipakai aplikasi lain
SOLUTION:
    1. Cari PID yang pakai port 5000:
       netstat -ano | findstr :5000
    
    2. Kill process:
       taskkill /PID <nomor> /F
    
    3. Atau ubah port di backend/app.py (baris terakhir):
       socketio.run(app, host='0.0.0.0', port=5001, ...)

─────────────────────────────────────────────────────────────────

ERROR 5: "ValueError: Invalid async_mode"
──────────────────────────────────────────
CAUSE: Pakai versi lama (eventlet mode)
SOLUTION:
    Versi ini sudah pakai threading mode.
    Pastikan menggunakan file dari ZIP ini, bukan versi lama.

─────────────────────────────────────────────────────────────────

ERROR 6: "Database error"
──────────────────────────
CAUSE: Folder data/ belum ada atau permission error
SOLUTION:
    mkdir data
    cd backend
    python -c "from database import init_database, seed_users; init_database(); seed_users()"

─────────────────────────────────────────────────────────────────

ERROR 7: Login gagal terus
───────────────────────────
CAUSE: Typo atau browser cache
SOLUTION:
    - Username: 1101223157 (cek tidak ada spasi)
    - Password: 1101223157 (sama persis)
    - Clear browser cache (Ctrl + Shift + Delete)
    - Coba Incognito mode (Ctrl + Shift + N)
    - Test di console:
      cd backend
      python
      >>> from database import verify_user
      >>> verify_user('1101223157', '1101223157')
      Harus return: {'nim': '1101223157', 'name': 'User 1'}

─────────────────────────────────────────────────────────────────

ERROR 8: Antivirus block Python
────────────────────────────────
CAUSE: Antivirus/firewall block Python atau Flask
SOLUTION:
    1. Tambahkan exception untuk Python.exe
    2. Tambahkan exception untuk folder v2v-windows-fixed
    3. Atau temporary disable antivirus
    4. Windows Firewall: Allow Python

─────────────────────────────────────────────────────────────────

ERROR 9: Browser tidak bisa akses
──────────────────────────────────
CAUSE: Firewall atau proxy
SOLUTION:
    - Check Windows Firewall settings
    - Disable proxy (Settings → Network → Proxy → OFF)
    - Coba browser lain
    - Coba http://127.0.0.1:5000 instead of localhost
