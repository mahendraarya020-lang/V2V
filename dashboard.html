📚 Key Literature References
Rajamani (2000) + Ploeg (2011)
PATH CACC PID+FF reference model. Defines string stability H(s) requirement.
Segata et al. (2014) — PLEXE
Purpose-built platooning simulator. Open-source benchmark for AR comparison.
Kaul et al. (2012) — AoI
Formal AoI definition Δ(t). M/D/1 peak AoI theory used in Analysis page.
3GPP TR 38.885
NR-V2X channel model: n=1.77, σ=3dB. Used in G-02 path loss model.
Brecht et al. (2018)
ECDSA-256 security overhead measured: mean 3ms, σ=0.5ms. Used in G-03.
Swaroop & Hedrick (1996)
String stability definition: |H(jω)| ≤ 1 ∀ω. Basis for FFT analysis (G-01).
